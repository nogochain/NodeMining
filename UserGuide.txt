NogoChain Node Mining Setup Instructions
=========================================

1. Right-click on start.bat and select "Open with Notepad"

2. Find the line: set MINER_ADDRESS=NOGO002decc673afa34952603e3d4d2340b07d219baeac55f51a0baca83129bb730c3c6acb5dea

3. Replace NOGO002decc673afa34952603e3d4d2340b07d219baeac55f51a0baca83129bb730c3c6acb5dea with your wallet address

4. If you don't have a wallet address:
   - Double-click to start the node first (it will use the default wallet address)
   - The web wallet page will automatically open in your browser
   - Generate and import your wallet through the web wallet interface
